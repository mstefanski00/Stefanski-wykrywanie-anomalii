# Stefanski-wykrywanie-anomalii
Kod do aplikacji webowej stworzonej w ramach pracy magisterskiej pt.: "Opracowanie metod automatycznego wykrywania i wizualizacji anomalii w wielowymiarowych szeregach czasowych" autorstwa Mikołaja Stefańskiego.

Instrukcja obsługi, przygotowana pierwotnie dla ankietowanych, znajduje się w pliku 'Intrukcja.pdf'. 

W razie jakichkolwiek problemów z konfiguracją środowiska, pobieraniem zależności lub dostępem do surowych danych: w pliku 'Instrukcja.pdf' znajduje się link do Dysku Google, na którym znajduje się archiwum z plikami.
